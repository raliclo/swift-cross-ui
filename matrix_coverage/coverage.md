# coverage

Which test apps have been run on which platform, and when.

`-` means no run has ever been recorded for that pair. It does **not**
mean passing.

And the inverse, which is the warning this file was missing: a recorded run
is **not** a passing run. Only `pass` is a pass. `no image` means the run
captured nothing, `capture n/a` means nobody established whether an image
exists, and `pass 1/2` means one of the two runs behind that cell did not
pass.

Generated from `results.csv2` — do not edit this file:

```sh
zsh matrix_coverage/coverage.zsh
```

`-` 代表該組合從未有任何一次執行被記錄下來，**不**代表通過。

`no image` 代表該次執行什麼也沒拍到，`capture n/a` 代表沒有人確認過影像是否存在，
而 `pass 1/2` 代表該格背後的兩次執行中有一次沒有通過。
