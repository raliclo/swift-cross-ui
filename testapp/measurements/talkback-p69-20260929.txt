# P69 on Android: what TalkBack actually says (2026-09-29)

Emulator swift-cross-ui-api36 (android-36 google_apis, arm64), TalkBack 16.0.0.738667889.
Speech captured with testapp/test_support/android_log_tts: a TTS engine that logs every
utterance (tag SCUI-TTS) and speaks none, installed as the default engine. Each element was
touch-explored with a real touchscreen event (sendevent on /dev/input/event1, via
/data/local/tmp/touch.sh); `adb shell input tap` bypasses the accessibility input filter and
TalkBack never sees it. Coordinates from `uiautomator dump --compressed` and a capture.

Verdict: every #123 claim holds as SPOKEN on Android. 'Close' and not 'X'; the hint after
Delete; 'Volume' with its value '40 percent'; the text labelled 'Half past twelve' is read as
that and '12:30' is not spoken although the node keeps text='12:30' (the override the P69
header describes); 'decorative' produces no speech at all.
